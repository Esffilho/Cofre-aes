Projeto de criptografia

Cofre AES

Guarde seus segredos com AES-256-GCM.

Privacidade: a senha-mestra nunca é armazenada pelo servidor.
1

Criar cofre

Escolha uma senha-mestra com pelo menos 8 caracteres.

Atenção: anote o ID e a senha-mestra. Não há como recuperar a senha se ela for esquecida.

2

Abrir cofre

Use o ID exibido após a criação e a mesma senha-mestra.

Se aparecer “senha-mestra incorreta”, confira se o ID e a senha pertencem ao mesmo cofre.

3

Segredos

Adicione registros e clique em “Ver” para consultar uma senha.
